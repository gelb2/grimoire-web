# 배포 절차

정본은 [grimoire-server/docs/DEPLOY.md](../../grimoire-server/docs/DEPLOY.md)다.
사용자별 GCP 설정, 웹 빌드 인자, preflight, 수동 배포와 롤백은 정본을 따른다.

로컬 실행은 [environments.md](environments.md#공개-준비용-로컬-실행-2026-11-13)를 따른다.
배포 스크립트는 이미지 push와 클라우드 변경을 수행하므로 로컬 검토 과정에서 실행하지 않는다.

이 문서는 `docs/AGENTS.md`의 DEPLOY 예외에 따른 포인터이며 서버 정본의 복사본이 아니다.
