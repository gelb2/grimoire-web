## 1. 수집하는 개인정보 항목

### 1-1. 회원가입 시 수집

| 항목 | 필수/선택 | 수집 목적 |
|------|----------|----------|
| 이메일 | 필수 | 계정 식별, 로그인 |
| 비밀번호 | 필수 | 인증 (bcrypt 해시 저장, 원문 미보관) |
| 필명(작가명) | 필수 | 서비스 내 표시 |
| 작가 공간 주소(slug) | 필수 | 고유 URL 생성 |

### 1-2. 소셜 로그인 시 수집

| 항목 | 출처 | 수집 목적 |
|------|------|----------|
| 소셜 계정 고유 ID | Google OAuth | 계정 연동 |
| 이메일 | Google OAuth | 계정 식별 |

### 1-3. 서비스 이용 중 자동 수집

| 항목 | 수집 시점 | 목적 |
|------|----------|------|
| IP 주소 | 댓글 작성, 좋아요 | 비로그인 중복 방지, 악용 차단 |
| 쿠키 ID | 비로그인 좋아요 | 중복 방지 (UUID, 개인 미식별) |
| 접속 기록 | 페이지 방문 | 서비스 운영, 조회수 통계 |

### 1-4. 결제 시 수집

| 항목 | 수집 시점 | 목적 |
|------|----------|------|
| 결제 거래 번호 | 크레딧 구매 | 결제 확인, 환불 처리 |

> 신용카드 번호, 계좌번호 등 민감 결제 정보는 서비스가 직접 수집하지 않으며, 결제 대행사(PayApp)가 처리합니다.

## 2. 개인정보의 이용 목적

| 목적 | 상세 |
|------|------|
| 서비스 제공 | 회원 인증, 작가 공간 운영, 에피소드 열람 |
| AI 기능 | 테마 생성 시 작가의 구술 텍스트를 AI(Anthropic Claude)에 전달 |
| 보안 | reCAPTCHA(Google)를 통한 봇 방지, IP 기반 악용 차단 |
| 통계 분석 | 조회수, 인기 작품 순위 등 서비스 개선용 익명 통계 |
| 결제 처리 | 크레딧 구매 및 환불 |

| 항목 | 보유 기간 | 파기 방법 |
|------|----------|----------|
| 회원 정보 (이메일, 이름 등) | 회원 탈퇴 시까지 | 탈퇴 후 즉시 삭제 |

| 재가입 방지 기록 | 영구 (가입 횟수만 저장, 개인정보 미포함) | — |

## 4. 개인정보의 제3자 제공

서비스는 원칙적으로 개인정보를 외부에 제공하지 않습니다. 다만, 다음의 경우 예외로 합니다:

| 제공 대상 | 제공 항목 | 목적 |
|----------|----------|------|
| Google (reCAPTCHA) | 브라우저 행동 패턴 (IP 등) | 봇 방지 |
| Google (OAuth) | 이메일, 소셜 ID | 소셜 로그인 |
| Anthropic (Claude API) | 테마 구술 텍스트 | AI 테마 생성 |
| PayApp (결제 대행) | 결제 금액, 거래 번호 | 결제 처리 |
| Microsoft Azure | 서버 운영 데이터 | 클라우드 인프라 |

> 원고 원문은 Anthropic을 포함한 제3자에게 제공되지 않습니다. AI 테마 생성 시 전달되는 것은 작가가 입력한 '분위기 설명' 텍스트뿐입니다.

## 5. 쿠키(Cookie) 사용

| 쿠키 이름 | 목적 | 유효 기간 |
|----------|------|----------|
| `grimoire_token` | 로그인 인증 (JWT) | 7일 |
| `grimoire_anon` | 비로그인 사용자 식별 (좋아요 중복 방지) | 세션 |
| Google reCAPTCHA 쿠키 | 봇 방지 | Google 정책에 따름 |

- 모든 인증 쿠키는 `HttpOnly`, `Secure`, `SameSite=strict` 플래그가 설정되어 있습니다.
- 쿠키 거부 시 일부 기능(로그인, 좋아요 등)이 제한될 수 있습니다.

## 6. 데이터 분석 활용

1. 서비스는 업로드된 원고에서 **비식별 메타데이터**(장르 분류, 키워드 빈도, 분량 통계)를 추출하여 서비스 개선 및 시장 분석에 활용할 수 있습니다.
2. 원고 원문 텍스트는 분석 결과물에 포함되지 않습니다.
3. 집계 데이터는 최소 10건 이상의 작품이 포함된 경우에만 외부에 제공되며, 개별 작품이 특정되지 않도록 익명화됩니다.
4. 회원은 설정 페이지에서 데이터 분석 활용을 거부할 수 있습니다.
